Este repositório é um exercício de Infraestrutura como Código (IaC) utilizando o Terraform. O objetivo foi é treinar a sintaxe, a organização de módulos e os comandos essenciais da ferramenta antes de aplicá-los em provedores de nuvem como a AWS.

A atividade foi realizada com base em uma aula de um curso de Terraform online.

## Como visualizar

Para visualizar o que foi desenvolvido, recomendo navegar pelos arquivos de configuração. Você pode focar na leitura dos seguintes arquivos principais:

1. **[`main.tf`](https://github.com/DalgonaFox/TerraformProject/blob/main/main.tf):** Onde os recursos e provedores principais estão declarados.
2. **[`variables.tf`](https://github.com/DalgonaFox/TerraformProject/blob/main/variables.tf):** Onde estruturei os parâmetros e tipagens de entrada.
3. **[`output.tf`](https://github.com/DalgonaFox/TerraformProject/blob/main/output.tf):** Onde defini quais dados a infraestrutura deve devolver após o provisionamento.
